# Kuan Yin Ting Morning Chanting

Kuan Yin Ting morning daily chanting text for chanting leads to know when to hit instrument notes.

## Dependencies

- [Typst](https://typst.app/)
- [Git LFS](https://git-lfs.github.com/) (for `reference_image.jpg`)
- CJK font: `Noto Sans CJK SC` (or `Source Han Sans` / `MiSans`)

## Usage

```sh
typst compile chanting.typ
```
